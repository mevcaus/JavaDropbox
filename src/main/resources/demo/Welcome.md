# Welcome to the JavaDropbox demo

This is a live instance of [JavaDropbox](https://github.com/mevcaus/JavaDropbox), a self-hosted
file storage app built with Spring Boot and React. Everyone who opens the demo shares this one
account, so be kind.

Things to try:

- **Preview** a file by clicking its name: the PDF in `Documents`, the logo in `Pictures`, the
  source file in `Code`, or this page.
- **Upload** files with the Upload button.
- **Versions**: `Notes/todo.txt` has been uploaded three times. Open its version history and
  restore an older one, in place or as a copy.
- **Share** a file or folder with a link that works without an account.
- **Download** a whole folder as a ZIP.

Uploads, total storage and share-link lifetimes are capped, and everything here is put back the
way it was once a day.
